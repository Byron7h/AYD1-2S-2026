# Ejemplo del Core a los Requerimientos

Esta carpeta contiene el ejemplo que muestra cómo avanzar desde el core del negocio hasta los requerimientos y las matrices de trazabilidad. **Esto es lo que harán en AYD2**

## Contenido de la carpeta

### `Ejemplo_del_core_hasta_requerimientos.md`

Incluye el desarrollo completo del ejemplo:

- Identificacion del core del negocio y sus actores.
- Primera descomposicion en procesos del negocio.
- Casos de uso expandidos por proceso.
- Requerimientos funcionales (RF).
- Requerimientos no funcionales, restricciones y atributos de calidad.
- Criterios de aceptacion y objetivos del negocio.
- Matriz de stakeholders frente a requerimientos.
- Matriz de requerimientos frente a casos de uso.
- Matriz de stakeholders frente a casos de uso.
- Matriz de requerimientos frente a requerimientos.
- Codigo PlantUML e imagenes exportadas de los diagramas.

### Imagenes del ejemplo

Los archivos `image.png` hasta `image-6.png` son las imagenes exportadas de los diagramas incluidos en el ejemplo. Se conservan en esta carpeta para que puedan visualizarse directamente en Visual Studio Code o GitHub.

## Flujo del ejemplo

1. Identificar el core y los actores.
2. Descomponer el core en procesos del negocio.
3. Expandir los casos de uso.
4. Derivar requerimientos funcionales y no funcionales.
5. Relacionar los artefactos mediante matrices de trazabilidad.
